# Polymarket: Conditional Tokens

This crate extracts Polymarket Conditional Tokens events from Polygon.

## Module

- `map_events`: emits `conditional_tokens.v1.Events`

## Events

- `ConditionPreparation`
- `ConditionResolution`
- `PositionSplit`
- `PositionsMerge`
- `PayoutRedemption`

## Contract

- Conditional Tokens: `0x4d97dcd97ec945f40cf65f87097ace5ea0476045`

## Build

```bash
make build
```
