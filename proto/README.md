# Polymarket: Proto Definitions

This crate packages the protobuf schemas shared by the Polymarket Substreams crates.

## Schemas

- `conditional-tokens.proto`
- `ctf-exchange.proto`
- `fee-module.proto`
- `negrisk-adapter.proto`
- `safe-proxy-factory.proto`
- `uma-ctf-adapter.proto`

## Generate

```bash
make protogen
```
